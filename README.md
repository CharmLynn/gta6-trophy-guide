The best offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a roadmap to the platinum (about 200 hours, PowerPyx 4/10), the one missable trophy flagged, and a checklist whose progress is saved in the browser and can be exported and imported back. Filters by kind (story, missable, collectibles, activities, online) and a spoiler setting that hides story trophies until they are earned. All 55 are single-player — there are no online trophies.

## Run it

```sh
node serve.ts   # serves app/ at http://localhost:8080
```

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
